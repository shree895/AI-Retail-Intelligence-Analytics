# AI Retail Intelligence Dashboard

## Project Overview
This project is an end-to-end retail analytics and business intelligence solution built using Python, Machine Learning, and Tableau.

The project analyzes Brazilian e-commerce sales data to uncover customer insights, revenue trends, product performance, geographic analytics, and sales forecasting.

---

## Objectives
- Analyze retail sales performance
- Build executive KPI dashboards
- Perform customer segmentation using Machine Learning
- Create revenue forecasting dashboards
- Develop interactive business intelligence visualizations

---

## Dataset
Dataset Used:
Brazilian E-Commerce Public Dataset by OLIST

Files Used:
- olist_orders_dataset.csv
- olist_order_items_dataset.csv
- olist_customers_dataset.csv
- olist_products_dataset.csv
- product_category_name_translation.xlsx

## Project Workflow

### 1. Data Cleaning & Preprocessing
- Handled missing values
- Merged multiple datasets
- Removed duplicates
- Created revenue-related features

### 2. Exploratory Data Analysis
- Revenue trend analysis
- Product category performance
- State-wise sales analysis

### 3. Customer Segmentation
Implemented K-Means clustering to classify customers into:
- High Value Customers
- Medium Value Customers
- Low Value Customers

### 4. Forecasting & Business Intelligence
- Monthly revenue forecasting
- Geographic sales visualization
- Interactive executive dashboards

## Key Insights
- São Paulo generated the highest revenue contribution.
- High-value customers contributed disproportionately to revenue.
- Revenue showed clear seasonal fluctuations.
- Health & Beauty emerged as one of the top-performing categories.
